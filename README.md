# Integration of Value Stream Mapping and System Dynamics

A research-based manufacturing optimization project focused on improving a production line by integrating **Value Stream Mapping (VSM)** with **System Dynamics modeling**.

## Overview

This project analyzes a **hot water generator production line** to identify process waste, bottlenecks, rework causes, and manpower inefficiencies. Traditional VSM provides a static view of the production flow, so this project integrates **System Dynamics using Vensim** to better understand dynamic process behavior, resource utilization, and improvement opportunities.

## Project Objective

- Identify waste and bottlenecks in the production line
- Analyze cycle time, takt time, uptime, quality, and resource capacity
- Convert the current VSM into a System Dynamics model
- Evaluate the production line using Lean Box Score
- Propose Kaizen improvements for process optimization
- Improve manpower allocation and reduce rework

## Key Findings

- Dock-to-dock production time: **58 hours**
- First Time Through: **75%**
- On-Time Delivery: **100%**
- Takt time: **9 hours/unit**
- Workers reduced from **18 to 10**
- Failure/repair cases reduced from **13 to 7**
- Weekly labor cost saving: **₹1.04 lakh**
- Sales per person improved from **₹130,000 to ₹234,000**

## Kaizen Improvements

| Problem Area | Proposed Improvement |
|---|---|
| Painting defects | Clean metal surface before painting |
| Rust formation | Remove rust and apply rust-inhibiting primer |
| Supply chain delays | Improve supplier coordination and inventory control |
| Equipment malfunction | Apply regular preventive maintenance |
| Poor worker training | Provide instructor-led and on-the-job training |
| Manpower underutilization | Reallocate workers using takt time analysis |

## Results

The integration of **VSM and System Dynamics** helped identify process gaps more effectively than static VSM alone. The project proposed improvements in manpower utilization, equipment reliability, rework reduction, and production flow efficiency.

VSM helped identify waste and bottlenecks, while System Dynamics helped understand how process changes affect the overall manufacturing system.
